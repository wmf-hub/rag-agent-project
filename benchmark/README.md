# 检索评测（benchmark）

回答两个问题：

1. **混合检索 + 精排，到底比纯向量检索好多少？**
2. **相关性阈值该设多少？**

## 怎么跑

前置：Milvus 与 Ollama 可用（`docker compose up -d`，`ollama list` 能看到 embedding 模型）。

```bash
python benchmark/run_eval.py
```

可选参数：

| 参数 | 默认 | 说明 |
|---|---|---|
| `--top-k` | 10 | 召回池大小（四条链路共用） |
| `--keep` | 关 | 保留临时集合 `eval_kb`，便于排查 |

跑完打印对比表并写入 `benchmark/latest_result.md`。临时集合默认自动删除，不影响业务集合 `knowledge_base`。一次完整评测约 5~6 分钟（精排占大头）。

## 数据

| 文件 | 内容 |
|---|---|
| `corpus.json` | 24 篇基础制度文档（考勤/薪酬/报销/差旅/采购/IT/产品/行政/销售） |
| `distractors.json` | 12 篇**近义干扰文档**：分公司细则、海外版、旧版说明，与基础文档共享大量词汇但数字不同 |
| `queries.json` | 41 条基础 query |
| `queries_hard.json` | 16 条难例 query，多数需要从"看起来都对"的文档里挑出正确那份 |
| `queries_noanswer.json` | 8 条**知识库里没有答案**的 query，用来评估阈值的拒答能力 |

语料 36 篇 / 36 个 chunk；有答案 query 57 条，无答案 query 8 条。

**为什么要加干扰文档**：第一版只用 24 篇干净文档时，四种配置的 Recall@3 全是 100%，评测完全饱和、看不出差异。加入近义干扰后，纯向量的 Recall@1 掉到 86%，混合检索和精排的价值才显现出来。

query 类型：

| 类型 | 说明 |
|---|---|
| `keyword` | 术语能直接对上，BM25 的强项 |
| `paraphrase` | 口语化或换说法，向量的强项 |
| `numeral` | 「一万块」vs「10000 元」、「打八折」vs「80 折」，考中文数字归一化 |
| `conflict` | 与干扰文档高度相似，必须靠上下文区分（如总部 30 天 vs 华东 45 天） |

## 指标怎么算

在**文档粒度**上算，不看 chunk id（chunk 是切分策略的实现细节）：

- **Recall@1 / Recall@3**：Top-N 里出现 gold 文档的任意 chunk 即算命中
- **MRR@3**：命中位置倒数的均值（第 1 名 1.0，第 2 名 0.5，第 3 名 0.33）
- **拦截率**：无答案 query 里，最高分低于阈值（即返回"未找到"）的比例
- **误伤率**：有答案 query 里，最高分低于阈值（被误拒答）的比例

阈值扫描（0.05 / 0.1 / 0.2 / 0.3 / 0.5）就是拿"拦截率"和"误伤率"做权衡，找拐点。

## 对比的四种配置

| 配置 | 说明 |
|---|---|
| 纯向量 | 只走向量召回，按余弦相似度排序 |
| 混合检索 | dense + BM25 双路召回，RRF 融合 |
| 混合 + 精排 | 融合后再用 bge-reranker 精排 |
| 混合 + 精排 + 阈值 | 再叠加 `RERANK_SCORE_THRESHOLD`（默认 0.3） |

## 当前结果摘要

有答案集（57 条）：

| 配置 | Recall@1 | Recall@3 |
|---|---|---|
| 纯向量 | 86.0% | 100.0% |
| 混合检索 | 91.2% | 98.2% |
| 混合 + 精排 | 96.5% | 100.0% |

阈值权衡（57 有答案 / 8 无答案）：0.30 时拦截 87.5%、误伤 3.5%，是拐点。完整数据见 `latest_result.md`。

## 注意

- 语料是**模拟文档**，不是真实业务数据；数字用于比较配置间的相对差异，不代表真实业务的绝对水平。
- 语料 36 篇，随机基线的 Recall@1 约 2.8%，所以绝对数值天然偏高。
- 无答案集只有 8 条，一个样本就是 12.5pt，**阈值结论的置信度有限**，扩到 30+ 条会更稳。
- 已知盲区：「产假多少天」这类**相邻概念**（产假 vs 年假/病假）精排会给出 0.67 的高分，阈值拦不住，需要负样本挖掘或查询改写。
